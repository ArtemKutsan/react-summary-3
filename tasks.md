# Задание 1 — DogsGallery

## Цель

Создать приложение, которое загружает и отображает случайные фотографии собак.

## Требования к компоненту

Создать компонент `DogGallery`.

### Использовать

- `useState` для хранения:
  - массива URL изображений
  - состояния загрузки `isLoading`
  - отдельного состояния загрузки для:
    - добавления собаки
    - обновления всех собак
- `useEffect` для загрузки данных при первом рендере
- `axios` для HTTP-запросов

### API

```
[https://dog.ceo/api/breeds/image/random](https://dog.ceo/api/breeds/image/random)
```

---

## Функциональность

### При первом запуске

- Загружается 3 случайные собаки
- Пока идет загрузка — отображается текст:  
  `Загрузка...`

### Кнопки

- **Добавить собаку**
  - Загружает +1 новое фото
  - Добавляет в массив
  - Имеет отдельный индикатор загрузки

- **Обновить всё**
  - Полностью заменяет все фото на новые
  - Количество новых фото = текущему количеству
  - Имеет отдельный индикатор загрузки

- **Очистить всё**
  - Удаляет все фото из массива

---

## Дополнительно

- Отображать счетчик:

```
Загружено собак: X

```

- Ошибки обрабатывать через `try/catch`
- Логика загрузки должна быть асинхронной

---

## Критерии выполнения

- При открытии страницы видно 3 собаки
- Кнопка "Добавить собаку" увеличивает количество изображений
- Кнопка "Обновить всё" полностью заменяет изображения
- Во время загрузки отображается "Загрузка..."
- Индикаторы загрузки разделены по действиям
- Есть кнопка очистки
- Счетчик работает корректно

# Задание 2 — TodoApp

## Цель

Создать приложение для управления задачами с синхронизацией с сервером.

## Требования к компоненту

Создать компонент `TodoApp`.

### Использовать

- `useState` для хранения:
  - массива задач
  - текста новой задачи
  - состояния загрузки
  - состояния ошибки
- `useEffect` для загрузки задач при старте
- `axios` для HTTP-запросов

### API

```
[https://jsonplaceholder.typicode.com/todos?_limit=5](https://jsonplaceholder.typicode.com/todos?_limit=5)
```

---

## Функциональность

### При первом запуске

- Загружаются 5 задач с сервера
- Отображается индикатор загрузки

---

### Добавление задачи

- Отправляется `POST` запрос
- Новая задача появляется в списке
- Даже если API не сохраняет данные реально — локальное состояние обновляется

---

### Удаление задачи

- Отправляется `DELETE` запрос
- Задача удаляется из локального состояния

---

### Переключение статуса

- Отправляется `PATCH` запрос
- Можно отметить задачу выполненной / невыполненной

---

## Интерфейс

- Список задач
- Чекбокс выполнения
- Кнопка удаления
- Поле ввода новой задачи
- Кнопка добавления
- Индикатор загрузки
- Отображение ошибки (если есть)
- Счетчик прогресса (например: `3 из 5 выполнено`)

---

## Критерии выполнения

- При загрузке отображаются 5 задач
- Можно добавить новую задачу
- Можно удалить задачу
- Можно переключать статус
- Есть обработка ошибок
- Есть индикатор загрузки
- Локальное состояние синхронизировано с UI
